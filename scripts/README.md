# Scripts Directory

This directory contains utility, diagnostic, and historical scripts for the Mess Provisions Register:

- `diagnostics/`: Scripts used for verifying Supabase connectivity, table schemas, RLS policies, and data integrity.
- `fixes/`: One-off data transformation and component adjustment scripts used during development.
- `sql/`: Historical and auxiliary SQL migration files. The primary database schema remains at `/supabase_schema.sql`.
